# 漫剧色卡参考图生成器 (Color Palette Reference Sheet Generator)

根据用户提供的参考图，把整体色彩语言转化为一张**干净、专业、扁平化**的数字色卡设计图提示词。描述为类似 Figma 色彩系统页、Adobe Illustrator 设计文档、电影美术设定集、Visual Development Sheet、Design System 色彩规范页、Color Script Reference Board。

完整任务目标、输出结构（标题/核心色板/色块说明区域）、视觉要求与严格禁止项、最终输出要求，见 `references/色卡参考图生成器.md`。执行时**先读取该文件**再开工。

## 工作流

1. **读取参考图**：分析其整体色彩语言（主色、光照色、中间调/阴影、材质色、强调色）。
2. **生成扁平化色卡提示词**，结构严格按参考文件：
   - 16:9 横向构图，纯平面设计美学（Flat Design），无摄影/实物/纸张/3D 渲染感
   - 背景：纯色中性浅色（米白/灰白/暖白/冷白），完全平面、无纹理/阴影/质感
   - 标题区：顶部居中，主标题【项目名称】·【场景/集数/主题】·【色彩系统名称】；副标题【环境氛围描述】·【颜色数量】color system
   - 核心色板：默认 13 个（10~15）纯色矩形，同一水平线、尺寸一致，无渐变/阴影/描边/纹理/光泽/透视；按顺序：环境主色→光照色→中间调与阴影色→材质色→强调色；每块含 HEX 色值 + 功能标签
   - 色块说明：第一行 HEX（等宽字体），第二行功能标签（无衬线）
3. **附加扁平化约束**：无摄影、无纹理、无阴影、无景深、无胶片颗粒、无写实材质、无 3D 渲染、无手绘/水彩/插画/草图感、无 Mockup、无真实物体模拟。
4. **仅输出最终提示词**：不解释分析过程、不说明推导逻辑、不输出额外文字，直接给出可复制的中文图像生成提示词。

## 验收标准
交付的提示词能稳定生成一张扁平、整齐、克制的色卡规范页，强调色彩信息本身，且每个色块都带 HEX 与功能标签，可直接用于后续生图或美术对齐。
