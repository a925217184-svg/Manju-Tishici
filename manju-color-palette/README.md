# manju-color-palette · 漫剧色卡参考图生成器

> 根据你提供的参考图，把整体色彩语言转化为一张**干净、专业、扁平化**的数字色卡设计图提示词（类似 Figma 色彩系统页 / 电影美术设定集 / Color Script Board）。用于给项目统一色彩规范、喂给后续生图锁色。

---

## 一、这个技能做什么

输入一张参考图，输出一段中文 AI 图像生成提示词，用来生成一张**扁平化色卡规范页**（不是艺术插画、不是摄影、不是实物）。它只产「一张色彩系统页」，是上游输入，不直接产出视频或角色。

## 二、什么时候用

- 你提供参考图、要求提取配色。
- 需要生成色卡 / 色彩系统 / Color Script。
- 需要统一的漫剧 / 项目色彩规范。

## 三、工作流

1. **读取参考图**：分析整体色彩语言（主色、光照色、中间调 / 阴影、材质色、强调色）。
2. **生成扁平化色卡提示词**，严格按下方结构：
   - **16:9 横向构图**，纯平面设计美学（Flat Design），无摄影 / 实物 / 纸张 / 3D 渲染感。
   - **背景**：纯色中性浅色（米白 / 灰白 / 暖白 / 冷白），完全平面、无纹理 / 阴影 / 质感。
   - **标题区**（顶部居中）：主标题【项目名称】·【场景/集数/主题】·【色彩系统名称】；副标题【环境氛围描述】·【颜色数量】color system。
   - **核心色板**：默认 13 个（10~15）纯色矩形，同一水平线、尺寸一致，无渐变 / 阴影 / 描边 / 纹理 / 光泽 / 透视；顺序：环境主色 → 光照色 → 中间调与阴影色 → 材质色 → 强调色；每块含 **HEX 色值 + 功能标签**。
   - **色块说明**：第一行 HEX（等宽字体），第二行功能标签（无衬线）。
3. **附加扁平化约束**：无摄影、无纹理、无阴影、无景深、无胶片颗粒、无写实材质、无 3D 渲染、无手绘 / 水彩 / 插画 / 草图感、无 Mockup、无真实物体模拟。
4. **仅输出最终提示词**：不解释分析过程、不说明推导逻辑、不输出额外文字。

## 四、配套文件

| 文件 | 作用 |
|---|---|
| `references/色卡参考图生成器.md` | 色卡页生成规范：任务目标、输出结构（标题/核心色板/色块说明）、视觉要求与严格禁止项、最终输出要求 |

## 五、功能标签示例

暖光照射、天空雾色、石墙高光、木材主色、皮革阴影、金属暗面、布料高光、冷色反光、尘土中间调、血色强调、霓虹信号。

## 六、严格禁止

摄影渲染、纸张纹理、桌面环境、阴影、景深、镜头虚化、胶片颗粒、写实材质、3D 渲染、手绘感、水彩感、插画感、草图感、Mockup、真实世界物体模拟。

## 七、验收标准

能稳定生成一张扁平、整齐、克制的色卡规范页，强调色彩信息本身，且每个色块都带 HEX 与功能标签，可直接用于后续生图或美术对齐。

## 八、使用示例

输入：一张「暗黑童话森林」的参考图

→ 技能会：解析其主色（幽绿）/ 光照（冷月光）/ 阴影（深蓝黑）/ 材质（苔石）/ 强调（血红）等 → 输出一段 16:9 扁平色卡页提示词，含约 13 个 HEX 色块与功能标签，可直接生图作为全片色彩规范。
