# 色卡参考图生成器（Color Palette Reference Sheet Generator）

## 任务目标
请根据我提供的参考图，生成一段用于 AI 图像生成的「色卡参考图」提示词。

目标是将参考图中的整体色彩语言，转化为一张干净、专业、扁平化的数字色卡设计图。

请不要将其描述为艺术插画、摄影照片或实物拍摄，而应描述成类似：
- Figma 色彩系统页面
- Adobe Illustrator 设计文档
- 电影美术设定集
- 视觉开发参考页（Visual Development Sheet）
- Design System 色彩规范页
- Color Script Reference Board

---

## 输出结构

### 整体画面
- 16:9 横向构图
- 纯平面设计美学（Flat Design）
- 不得出现摄影元素、实物拍摄感、纸张印刷感、3D渲染感

### 背景设计
背景为纯色中性浅色填充：
- 米白色
- 灰白色
- 暖白色
- 冷白色

要求：
- 完全平面化
- 无纹理
- 无阴影
- 无纸张质感
- 无桌面环境
- 无材质表现

### 元素1：标题区域
顶部居中

主标题格式：
【项目名称】 · 【场景/集数/主题】 · 【色彩系统名称】

副标题格式：
【环境氛围描述】 · 【颜色数量】 color system

### 元素2：核心色板区域
- 默认13个颜色（10～15个）
- 同一水平线排列
- 纯色矩形
- 尺寸一致
- 无渐变、阴影、描边、纹理、光泽、透视

色彩顺序：
1. 环境主色
2. 光照色
3. 中间调与阴影色
4. 材质色
5. 强调色

每个色块必须包含：
- HEX色值
- 功能标签

### 元素3：色块说明区域
第一行：HEX色值（等宽字体）
第二行：功能标签（无衬线字体）

功能标签示例：
- 暖光照射
- 天空雾色
- 石墙高光
- 木材主色
- 皮革阴影
- 金属暗面
- 布料高光
- 冷色反光
- 尘土中间调
- 血色强调
- 霓虹信号

---

## 整体视觉要求

风格参考：
- 电影美术圣经（Art Bible）
- 色彩系统说明页
- Visual Development Sheet
- Design System Documentation
- Color Management Reference Page

构图要求：
- 清晰
- 整齐
- 克制
- 强调色彩信息本身

### 严格禁止
- 摄影渲染
- 纸张纹理
- 桌面环境
- 阴影
- 景深
- 镜头虚化
- 胶片颗粒
- 写实材质
- 3D渲染
- 手绘感
- 水彩感
- 插画感
- 草图感
- Mockup
- 真实世界物体模拟

---

## 最终输出要求

最终仅输出一段完整的中文 AI 图像生成提示词。

必须包含：
1. 画面比例与风格说明
2. 背景色描述
3. 标题与副标题
4. 色块数量
5. 每个色块HEX值
6. 每个色块功能标签
7. 扁平化限制条件
8. 无摄影、无纹理、无阴影等约束条件

### 输出规则
不要解释分析过程。
不要说明推导逻辑。
不要输出额外文字。
仅输出最终可直接用于图像生成的完整提示词。
