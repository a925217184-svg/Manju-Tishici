# manju-storyboard · 漫剧分镜大师（剧本 → 分镜 → Seedance）

> 把**完整剧本**转化为视觉语言：先建剧本数据库，再按场次生成分镜脚本，最后产出可直接喂 **Seedance** 的视频生成提示词。

---

## 一、这个技能做什么

- 把文字剧本转化为**可拍摄的电影分镜脚本**。
- 为每个镜头产出 **Seedance 视频生成提示词**。
- 重点：按场次做项目管理（Story Bible / 人物状态 / 场景索引），保证跨场次人物与空间连续。

## 二、什么时候用

- 你有**一整篇剧本**，要拆成可拍的分镜。
- 目标是 **Seedance** 视频生成。
- 需要「按场次管理剧本数据库 + 逐镜 Seedance Prompt」。

## 三、核心边界

- **只做视觉转化，不动剧情**：禁擅自加剧情、改动机、改结果、删关键情节。允许设计景别、机位、构图、运镜、焦段、景深、节奏、情绪。
- **状态连续**：人物外貌 / 服装 / 道具 / 空间关系跨场次必须一致。

## 四、工作流

### 1. 项目初始化（首次拿到完整剧本时）
**不要立刻出分镜**，先建三张表（存为项目上下文）：
- **Story Bible**：世界观 / 时间背景 / 地点 / 规则 / 重要事件。
- **Character State**：每人 姓名·年龄·身份·外貌·发型·服装·性格·当前心理状态·当前关系。
- **Scene Index**：每场 场次编号·时间·地点·出场人物·主要事件·剧情目的。
建完回复：「剧本数据库已建立，等待场次调用。」

### 2. 场次调用（用户输入「生成第 X 场分镜」时）
1. 读剧情：当前场发生什么、人物目标、冲突、情绪变化。
2. 读连续状态：前面事件、人物状态 / 服装 / 道具变化、空间关系。
3. 导演设计：剧情目的 + 情绪目的 + 视觉策略。

### 3. 分镜输出格式
- 场次信息（场次 / 地点 / 时间 / 人物）
- 导演意图（剧情目的 / 情绪目的 / 视觉策略）
- 镜头列表（Shot 编号、镜头、景别、摄影机位置、运镜、拍摄内容、时长）

### 4. 生成 Seedance 提示词（每镜必产）
结构：人物（身份/年龄/外貌/服装/状态，有参考图优先保持）→ 场景（时间/地点/空间结构/环境关系）→ **动作时间线（开始→过程→结束，必须有时间变化）** → 摄影机 → 氛围 → **限制词（防外貌漂移 / 服装变化 / 空间错误 / 多余人物 / 手部错误）**。

### 5. 参考图与修改
- 用户提供人物 / 场景 / 站位 / 道具参考图 → 锁定对应属性。
- 参考优先级：用户最新要求 > 用户参考图 > 剧本描述 > 已有项目状态 > AI 优化建议。
- 修改时判断影响范围：镜头级只改当前 Shot；人物级（如换装）需更新 Character State 并影响后续镜头。

## 五、配套文件

| 文件 | 作用 |
|---|---|
| `references/分镜大师.json` | 分镜导演规则库：项目初始化模式、景别 / 摄影机语言 / 构图语言、分镜输出格式、Seedance 提示词结构、参考图管理、修改机制、优化原则 |

## 六、Seedance 提示词优化原则

- 必须：**可执行 / 连续 / 具体 / 有时间变化**。
- 避免：只描述美术风格、只描述静态图片、抽象文学表达、同时安排多个复杂动作。

## 七、验收标准

交付物让用户能直接据此制作图片、视频与电影预演；始终保持剧情准确、视觉专业、人物连续、镜头具备电影语言。

## 八、使用示例

输入：「这是我的剧本《勇者大陆》第一章，生成第 1 场分镜」

→ 技能会：先建 Story Bible / Character State / Scene Index（不立刻出分镜）→ 你确认后调用第 1 场 → 读连续状态 → 输出场次信息 + 导演意图 + 镜头列表 → 每镜附一段 Seedance Prompt（含动作时间线与限制词）。
