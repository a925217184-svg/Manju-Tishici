# manju-composition · 漫剧构图大师（电影感单张生图）

> 把任何视觉想法——场景描述、故事片段、图片需求、原始提示词、简单概念——设计成**一个电影镜头**的生图提示词，让成品像「电影真实截图」，而非 AI 插画 / 游戏原画 / CG 概念图 / 海报。

---

## 一、这个技能做什么

把视觉想法转化为**单张**电影感生图 Prompt（含 Negative Prompt 与摄影设计结构）。它管「一张关键帧 / 概念图」，不做连续视频。

## 二、什么时候用

- 要生成电影感图片、优化生图提示词。
- 做漫剧 / 短剧关键帧或概念图。
- 需要「真实摄影机观察感」而不是 AI 插画感。

## 三、工作流（9 步）

1. **判断画面主体**：人物 / 动物 / 建筑 / 自然环境 / 产品 / 机械 / 生物 / 事件（不要让所有元素同时当主体）。
2. **判断场景类型并强化对应元素**：自然环境 / 建筑空间 / 人物剧情 / 科幻幻想 / 商业摄影（各类型强化项见 `references/构图大师.json`）。
3. **建立空间层次**：前景（入口 / 距离感）→ 中景（主体）→ 背景（世界规模 / 氛围 / 时间）。
4. **选画幅与镜头**：21:9 史诗 / 16:9 剧情 / 4:5·2:3 人像 / 1:1 产品；广角 / 标准 / 长焦 / 微距按主体选。
5. **设计光影**：所有光必须有来源（自然光 / 人工光），说明来源方向、强弱、影响范围；避免无来源发光、均匀照亮、假光。
6. **强化材质真实**：自然 / 建筑 / 人物 / 产品各自材质关键词。
7. **控制色彩**：真实电影低饱和、历史暖灰、科幻冷色、惊悚强阴影、商业干净。
8. **默认加电影质感词**：`cinematic photography` / `realistic camera capture` / `natural exposure` / `atmospheric perspective` / `realistic depth of field` / `subtle film grain` / `cinematic color grading`。
9. **排除 AI 感**：AI 插画感、CG 渲染感、游戏截图感、过度锐化、塑料材质、不真实光源、过高饱和、杂乱构图等。

## 四、提示词生成顺序（严格 12 步）

媒介类型 → 画幅 → 摄影机 → 主体 → 环境 → 空间关系 → 光线 → 材质 → 色彩 → 氛围 → 电影质感 → 负面约束。

## 五、配套文件

| 文件 | 作用 |
|---|---|
| `references/构图大师.json` | 电影构图全规则库：场景类型、画幅自动选择、摄影机语言、光影设计、材质真实系统、色彩控制、禁止生成元素、Prompt 生成顺序、输出格式 |

## 六、输出格式

- **电影感优化提示词**：完整可复制 Prompt。
- **负面约束**：Negative Prompt。
- **摄影设计结构**：场景类型 / 主体 / 画幅 / 镜头 / 构图 / 光源 / 色彩 / 材质 / 氛围。
- **优化说明**：强化的摄影逻辑、空间关系、真实感、电影质感。

## 七、验收标准

能稳定生成「像电影真实截图」的画面：明确主体、真实空间层次、可追溯光源、真实材质与电影质感，且不含 AI 感元素。

## 八、使用示例

输入：「雪夜古战场，残阳，一名将军孤身立于尸横遍野的城门废墟前」

→ 技能会：判定主体＝将军（中景）、场景＝建筑空间（废墟），建立前景碎石 / 中景将军 / 背景城门与雾，选 21:9 史诗画幅＋标准略长焦，设计黄昏侧逆光，强化石木金属材质，低饱和电影灰，叠电影质感词，排除插画感，输出完整 Prompt + Negative + 摄影设计结构。
