# 漫剧构图大师 (Cinematic Composition)

把任何视觉想法设计成**一个电影镜头**，让最终画面像电影中的真实截图，而非 AI 插画 / 游戏原画 / CG 概念图 / 海报。

完整规则、场景类型识别、前中后景层次、画幅与镜头选择、光影与材质真实系统、色彩控制、禁止元素、提示词生成顺序与输出格式，见 `references/构图大师.json`。执行时**先读取该文件**再开工。

## 核心原则

先判断「这个画面应如何被摄影机看到」，再生成「AI 应如何理解这个画面」。目标是设计电影镜头，不是写一张漂亮图片。

必须考虑的维度：导演意图、摄影机位置、镜头语言、空间关系、光源逻辑、材质真实性、色彩控制、氛围叙事。

## 工作流

1. **判断画面主体**：人物 / 动物 / 建筑 / 自然环境 / 产品 / 机械 / 生物 / 事件。不要让所有元素同时成为主体。
2. **判断场景类型并强化对应元素**：自然环境、建筑空间、人物剧情、科幻幻想、商业摄影（各类型强化项见参考文件）。
3. **建立空间层次**：前景（入口/距离感）→ 中景（主体）→ 背景（世界规模/氛围/时间）。
4. **选画幅与镜头**：21:9 史诗/风景，16:9 电影截图/剧情，4:5·2:3 人像，1:1 产品；广角/标准/长焦/微距按主体选择。
5. **设计光影**：所有光必须有来源（自然光/人工光），说明来源方向、强弱、影响范围；避免无来源发光、均匀照亮、假光。
6. **强化材质真实**：自然/建筑/人物/产品各自材质关键词。
7. **控制色彩**：按真实电影/历史/科幻/惊悚/商业选方案，默认低饱和、自然色彩、电影灰。
8. **默认加电影质感词**：cinematic photography、realistic camera capture、natural exposure、atmospheric perspective、realistic depth of field、subtle film grain、cinematic color grading。
9. **排除 AI 感**：AI 插画感、CG 渲染感、游戏截图感、过度锐化、塑料材质、不真实光源、过高饱和、杂乱构图等。

## 提示词生成顺序（严格按此 12 步）
媒介类型(真实电影摄影) → 画幅 → 摄影机 → 主体 → 环境 → 空间关系 → 光线 → 材质 → 色彩 → 氛围 → 电影质感 → 负面约束。

## 输出格式
- 电影感优化提示词（完整可复制 Prompt）
- 负面约束（Negative Prompt）
- 摄影设计结构：场景类型/主体/画幅/镜头/构图/光源/色彩/材质/氛围
- 优化说明：强化的摄影逻辑、空间关系、真实感、电影质感

## 验收标准
交付的提示词能稳定生成「像电影真实截图」的画面，具备明确主体、真实空间层次、可追溯光源、真实材质与电影质感，且不含 AI 感元素。
