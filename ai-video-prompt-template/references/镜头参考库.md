# 镜头参考库（景别 / 画幅 / 运镜 / 镜头类型 / 构图 / 机位 全词表 + 写作铁律）

> **定位**：把分散在 `template.md`（运镜类型库、节奏公式）、`manju-storyboard/references/分镜大师.json`（景别7种、摄影机语言10种、构图7种）、`manju-composition/references/构图大师.json`（画幅、镜头类型、空间层次）里的镜头词汇**集中到一处**，并补入 `ai-video-prompt-template` 用户长期踩坑沉淀的**真实机位参数**与**运镜写作铁律**。
> 本库是「查词 + 选机位 + 写运镜」的工具书，不替代三层骨架本身。写分镜时先来这里定景别/机位，再回到 `template.md` 填四段式画面。
> ⚠️ 镜头/运镜词库原先内嵌在 template.md 与两个 manju 技能里，本库是它们的**统一抽取版**；如两处表述冲突，以本库 + SKILL.md 的「用户定制铁律」为准。

## 1. 景别（Shot Size）· 7 种 + 竖屏

| 景别 | 画面范围 | 人物占画面 | 何时用 | 表情写法 |
|---|---|---|---|---|
| **大远景 (EWS)** | 人在环境中极小，强调世界尺度 | <1/10 | 史诗开场、战场全景、世界观展示 | 不写表情 |
| **远景 (WS)** | 全身 + 大量环境 | ~1/5~1/8 | 定场、阵列、群像 | 不写表情 |
| **全景 (FS)** | 全身入画，环境退居背景 | 全身 | 走位交代、站位关系 | 不写表情 |
| **中景 (MS)** | 腰以上 | 半身 | 对白主场、动作启动 | 可写明显表情 |
| **近景 (CU-ish)** | 胸以上 | 大头 | 情绪、反应、台词特写 | 写表情 |
| **特写 (CU)** | 脸/手/道具局部 | 占满 | 关键瞬间、微表情、持物 | 写微表情 |
| **微距 (Macro)** | 材质/纹理级 | — | 产品、血珠、铠甲划痕 | — |
| **9:16 竖屏特化** | 手机画幅，单人常占 1/5 高（见 §6 实机参数） | 见各套机位 | 买量短片默认竖屏 | 按景别 |

> 实战经验（割草/实机）：第三人称主角占画面高约 **1/5~1/6** 才是「游戏录屏感」；占 1/3 以上 = 贴脸电影感（用户常打回）。详见 §6。

## 2. 画幅（Aspect Ratio）

| 画幅 | 适用 | 备注 |
|---|---|---|
| **21:9** | 史诗/风景/建筑/世界观 | 电影宽银幕 |
| **16:9** | 剧情场景/人物环境关系/横版场景图 | 通用 |
| **9:16** | 买量短视频/手机竖屏 | 用户项目默认 |
| **4:5 / 2:3** | 人像/角色展示 | 单角色立绘 |
| **1:1** | 产品/静物 | — |

> ⚠️ 横版俯视场景（如割草大地图）若写 16:9，视场要从 50° 收到 **42°** 才能维持主角占画面高 1/6（高度/俯角不变）。

## 3. 摄影机语言 / 运镜（Camera Movement）· 全词表

### 3.1 基础 10 种（来自 分镜大师.json）
固定镜头、推镜、拉镜、横移、跟拍、环绕、升降、手持、长镜头、主观镜头。

### 3.2 模板原型库的运镜示例（来自 template.md，按功能分）
- **开场定场**：广角前推 / 大远景横摇 / 俯拍下降
- **主体登场**：平移跟拍 / 缓慢上摇 / 剪影现身
- **动作启动**：极速推拉 / 手持晃动 / 定点变焦
- **追踪**：跟尾追踪 / 贴地跟拍 / 甩焦切换
- **对抗互动**：环绕锁焦 / 正反打 / 主观视角
- **强调**：升格慢放 + 震镜回弹 / 急推急停
- **高潮**：多目标同步追踪 / 螺旋环绕 / 多机位快切
- **收尾**：全屏震动定格 / 缓慢拉远 / 黑场渐隐 / 凝固特写

### 3.3 用户定制「常用机位词库」（避免重复，来自 SKILL.md）
横移跟随 / 过肩正反打 / 低角度缓推 / 过肩特写 / 微距 / 甩焦 / 环绕锁焦 / 固定小幅推轨 / 手持轻摇 / 仰角近景 / 背影跟拍 / 拉升定格。

> ✅ checklist：运镜类型不重复——定场→跟拍→环绕→升格→俯拍→定格交替使用。

## 4. 镜头类型 / 焦段（Lens & Focal Length）

| 镜头 | 适合 | 强化 | 风险提示 |
|---|---|---|---|
| **广角** | 巨大空间/建筑/风景 | 空间尺度、环境关系 | ⚠️ 视场过大（78°/65°）会把远景拍小、人相对偏大——**隐藏杀手** |
| **标准** | 剧情/人物 | 自然观察感 | 实机录屏用 45°~50° 标准镜头（非广角） |
| **长焦** | 情绪/远距观察 | 空间压缩 | — |
| **微距** | 产品/细节 | 材质表现 | — |

### 4.1 视场角（FOV）对照（用户实测，关键！）
| 用途 | 离地高 | 距人 | 俯角 | 水平视场 | 人物占画面高 |
|---|---|---|---|---|---|
| 第三人称射击（实机录屏） | ~10m | ~10m | 35° | 45°（标准） | ~1/5（1080≈200px） |
| 2.5D 斜俯视闯关 | 身后上方 ~3m | — | 45–50° | — | ~1/4 |
| 割草俯视（第三套） | ~12m | — | 60° | ~50°（横版收42°） | ~1/6 |
| 第三人称射击补救抬升 | 10→12m | — | 35→40° | — | — |

> ⚠️ **补救顺序**（主角占比偏大时）：先抬高度(10→12m) → 抬俯角(35→40°) → 最后拉距离；**绝不把 1/5 改回 1/3**。决定性的是高度与俯角，不是距离。

## 5. 构图（Composition）· 7 种 + 空间层次

### 5.1 构图语言
对称构图、三分法构图、框架构图、前景遮挡、深度构图、引导线构图、负空间构图。

### 5.2 空间层次（必须建立，来自 构图大师.json）
- **前景**：增强真实摄影感、增加距离、建立观看入口（岩石/植物/建筑边缘/阴影/桌面元素）。
- **中景**：主体区域（人物/建筑/产品/核心事件）。
- **背景**：世界规模/氛围/时间感（远山/天空/城市/雾气/光线）。

### 5.3 机位决定构图边界（用户铁律）
机位决定构图边界：**框不到的人/物不写**。单人特写不硬塞配角；中近景只写「背景虚化队列」；远景阵列才写军阵四要素。写「画面」只描述看到的内容，不描述「机位能看到」。

## 6. 机位 / 角度（Camera Position & Angle）

| 角度 | 写法 | 适用 |
|---|---|---|
| 平视 | 平视略仰 5° / 平视 | 对白、常规 |
| 仰角 | 仰角近景 / 贴地仰摇 | 英雄感、大型道具（防玩具感） |
| 俯角 | 斜俯 45° / 俯拍下降 / 高位斜俯 60° | 俯视战场、阵列、走位图 |
| 侧面 | 右前方 2.5m / 侧方 N 米外 | 客观机位、正反打 |
| 正面 | 正面朝向镜头 | 对视、看 UI（需正面平视） |
| 背面 | 背影跟拍 / 身后 | 跟随、收尾拉升 |
| 主观 | 主观视角 / POV | 第一人称、代入 |

### 6.1 实机录屏感机位（用户三测定稿，第三人称射击）
- 离地约 **10m**／距人约 **10m**／俯角 **35°**／水平视场 **45°** 标准镜头（非广角）／人物占画面高约 **1/5**（横向约 1/10）／地平线压到上方 **1/6**／下方七成是地面。
- 一镜到底内**不改高度俯角**，只做固定半径 10m 水平环绕＋平移跟随。
- NEG 必带：CG宣传片质感、电影镜头/调色、柔光滤镜、慢镜头、稳定器丝滑、无人机俯瞰、第一人称、过肩瞄准；机位与人物同高、平视、贴近主角、主角占画面高 1/3 以上、浅景深。

### 6.2 2.5D 斜俯视闯关（另一套，别混用）
45–50°／身后上方约 3m／固定跟随、不环绕不甩镜／主角约占画面高 1/4／9:16 竖屏；仅结尾立绘可切正面平视。

### 6.3 甩视角（模型最难，翻车就拆三条独立生成）
绕到侧前方看正脸＋露追兵 → 迅速甩回背后位；模型最难，翻车就拆三条独立生成。

## 7. 运镜写作铁律（用户定制，必守）

### 7.1 四要素 vs 两要素（看用户当次偏好）
- **要能直接落地执行 / 不要笼统** → 四要素写死：
  `景别（人物占画面比例）｜机位角度与高度｜运动方式＋速度/距离/秒数｜落幅停在哪`
  例：「中景（腰以上），机位在角色右前方 2.5 米、平视略仰 5°，出拳瞬间 0.3 秒急推 1.5 米到近景，落幅锁定收拳侧脸」。
- **别写太复杂 / 给 AI 留发挥空间** → 只写景别＋运动（平均 8 字）：
  「中景，小幅环绕。」删掉画面占比、机位距离角度、运动秒数、落幅。
- ⚠️ **判断口径**：用户说"要能直接落地"→ 四要素；用户说"别写太复杂"→ 两要素。**问一句比猜好**，改完在交付说明写「别往回加参数」。

### 7.2 落幅是跨镜衔接锚
`景别 ＋ 运动 ＋ 落幅` 是跨镜衔接的锚；只写"景别＋运动"时，下一镜易接不上（机位或朝向跳变）。收到"机位跑偏"反馈时单独开「机位兜底（可选）」块，不破坏 NEG 分流。

### 7.3 来袭方向锁（防方向反转）
写导弹/箭雨/落石/爆炸「从画外来袭」时，必须用语义相对方位写明来向，不能只写角色的身后/身前（AI 会真把弹道画到身后）：
1. 先定角色朝向（「正面朝向镜头」）；
2. 再写来向（「他抬眼望见**镜头这一侧**的天上，成排导弹从画面上方正朝他压下来」）；
3. 爆炸落点写相对关系（「就在**他与镜头之间**的空地上炸开」）。
> 追逃方向铁律（见 SKILL.md/working memory）：**威胁源必须摆在镜头这一侧（画面近端），绝不摆画面深处远景**。

### 7.4 客观机位（用户说「用客观一点的角度」）
去掉主观代入机位（贴背后跟随、随主体快速前推、过肩代入），换成旁观者机位——机位固定在侧方 N 米外、给全/远景、镜头基本不动（或仅极慢横移），正文显式写「**不贴身、不跟随、不代入**」。拆镜时可一镜给场上主体、一镜给环境/群像，两镜都用固定机位。

### 7.5 分镜 ≠ 镜头：一镜一句
每一个说话人 = 一个独立镜头；同一人连说两句且情绪递进也拆两镜（换机位换景别）。无台词的动作/反应/定场也各自成镜。每个带台词镜头单独写景别/机位/运动/落幅，**不复用上一镜机位描述**。

## 8. 复用方法

- 本库是查词工具书，不每次重写。每片只做：① 定画幅（默认 9:16）；② 按 §1 选景别、按 §6 定机位（含真实参数）；③ 按 §3 挑运镜避免重复；④ 按 §7 决定四要素还是两要素写法。
- 改风格/改工具时：横版场景图视场收 42°（§2）、实机感别用广角（§4）、俯视空地必须纯文生图（带平视街景参考图会把构图钉成平视）。
- 与 `combat-handbook.md`、`表情参考库.md` 分工：本库管「机位/运镜/构图」，表情库管「人脸情绪」，打斗手册管「打击反馈/破坏」。三者互不替代。
