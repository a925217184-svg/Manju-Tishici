# 巨物 / 怪兽 / 灾难场景模版（原理与词库）

> **定位变更（2026-11-07 · v1.4）**：本文件的机制已**全部焊死**进 `ai-video-prompt-template` 的 v1.4 主结构，不再是「命中才补的可选加成块」。现在它承担两件事：①解释这些机制**为什么有效**（原理）；②提供可直接抄的**词表**（尺寸锚、受力动词、genre 负词）。
> 经验来源：用户实测一段「深海章鱼毁城」15s 提示词效果极好（巨物有体积感、动作有重量感、氛围也对），用户随后拍板「焊死进结构」，并要求整体骨架向这段提示词对齐。

## 0. 触发词
巨物、怪兽、巨型生物、怪物、灾难、城市破坏、毁城、哥斯拉、克苏鲁、章鱼、触手、海怪、地震、海啸、陨石、崩塌……（任一出现在脚本／需求里）。

## 1. 这段章鱼提示词为什么有效（套路拆解）
用户原话：「巨物有体积感，动作有重量感，氛围也对」。拆出 5 条可复用机制：

**(1) 体积感 = 尺寸对比锚，不写「巨大」**
- 原文：`身形高耸于周边摩天大楼之上` —— 用已知物体（摩天楼）当比例尺，AI 才会把生物画到楼顶高度。**只写「巨大」「庞大」会被画成中等体型**。
- 备选锚：比 XX 建筑高 / 触手横跨整条街 / 阴影盖住半个广场 / 头部没入云层 / 成年人只到它脚踝。

**(2) 重量感 = 运动信条 + 受力结果动词**
- 运动信条写死：`全程保持移动` —— 巨物最忌「站着摆 pose」，一停就显假、显轻。原稿写作「绝不停滞或摆姿势」，**v1.4 落地时按「正向板块禁否定句」改成纯正向表述**，「静止摆姿／缓慢开场／中途减速」交给题材负词组兜底，信息不丢。
- 受力结果动词（**禁用「破坏」这种笼统词**）：`碾碎公交`、`拽倒玻璃大楼`、`撕裂楼体`、`震裂路面`、`将车辆抛向空中`、`极端应力下解体`、`轰然坍塌`。动词必须带「谁对谁施加了多大力量」才出重量。

**(3) 动量连续 = 每镜强调不减速**
- 原文：`毫不减速`、`始终不减冲势`、`仍继续着无情的推进`。多镜连续时，**每一镜都要重申运动不中断**，否则 AI 会在一镜里把巨物「定住」或「慢下来」。⚠️ 这是原稿写法，**v1.4 落地时改成正向表述**（见 §4），「中途减速／动作停顿／环境静止」移到题材负词组。

**(4) 解剖锁 = 预防性写死（防 AI 翻车的精髓）**
- 原文：`八条触手始终保持完整连接、清晰分离、解剖结构正确，并在整个过程中始终清晰可见` —— 这是**主动**把 AI 最常翻车的点（多肢体、缠绕、断裂、错位、消失）用正描述钉死，**比事后在负词里禁更有效**。
- 同理适用于：多手多脚生物、成群敌人、机械多关节、分体式机甲。

**(5) 逐镜 光线／特效 独立成行**
- 原文每镜拆「镜头／动作／光线／特效」四字段。灾难片里光线是氛围主驱动（暴风雨白昼光、闪电、逆光火光、钢蓝暴雨光），单列更可控、不相互稀释。
- **v1.4 起这一条已焊死为所有题材的默认项**：【分镜】每镜固定 `运镜：`／`画面：`／`光线：`／`特效：` 五行，光线与特效两行任何题材都不许省。

## 2. v1.4 里这些机制落在哪个板块（对照表）

| 原脚本字段 | v1.4 板块 | 状态 |
|---|---|---|
| 时长 15 秒 / 画幅比例 16:9 | 【风格锁】`时长：`／`画幅：` | 默认 |
| 风格 / 视觉风格 | 【风格锁】`质感：`／`视觉风格：` | 默认（质感只选一种） |
| **怪兽设计** | **【资产锁】对应资产的 `+ 描述`**（尺寸锚＋外观，不含解剖锁） | 默认 |
| 动态表现 | 【动态锁】运动信条／动量连续／解剖锁 | 巨物、追逃等持续运动题材必加 |
| 0:00–0:02 镜头／动作／光线／特效 | 【分镜】每镜五行 | **光线／特效焊死必写** |
| 音频设计 | 【音频锁】环境底噪／动作点音 | 默认（逐镜不另列音效行） |
| 反向提示词 | 【负面提示词】通用组 ＋ 题材组 | **题材组固定追加** |

**怪兽设计为什么不另立板块**：资产锁本来就是「`@图` ＋ 一段对这个资产的描述」。给了一张刘备角色图、但要他成为巨人，就写 `@刘备 作为刘备角色的参考锚定图 + 身形高耸于摩天楼之上、…`，与章鱼那段整块「怪兽设计」等价。**无参考图时走文字定金**：`深海章鱼 作为巨兽形象的文字定金 + 描述`，不带 `@`；一旦上传同名图，换成 `@深海章鱼` 即可。

**已删除：全局【特效锁】**。把全片特效在开头一次描述完不符合生成逻辑，特效是跟着每一镜发生的。
- 逐镜环境破坏（暴雨／粉尘／碎裂／玻璃幕墙／冲天水柱）→ 全部写进【分镜】的 `特效：` 行。
- 「道具平时不发光、只在唤起 UI 那瞬发光」这类**状态切换**→ 写进【资产锁】对应资产的 `+ 描述`，或【风格锁】的「一致性」行。

**【动态锁】位置**：【风格锁】之后、【音频锁】之前（与主结构板块表一致），不是早期草稿里写的「资产锁之后、风格锁之前」。

## 3. genre 专属负词（题材组·巨物灾难，整组照抄）

```
多余肢体、触手缺失、触手缠绕打结、触手断裂脱离、解剖结构错误、
吸盘变形、漂浮的碎片、不真实的破坏、失重物理、缓慢开场、静止摆姿、
中途减速、动作停顿、环境静止、瞬移、低分辨率特效
```

> v1.4：这一组已焊死为【负面提示词】的「**题材组·巨物灾难**」，命中题材即整组追加，**不许只挑两三个词**。通用组（CG 宣传片质感／CG 过场动画／卡通外观／CGI 质感／塑料质感／字幕／水印／闪烁等）另行写一次，**两组不重复**。
> ⚠️ 「不是 CG 宣传片、不是卡通」这类画风排除句**只准写在负面区**，【风格锁】质感行一个否定词都不留（正向写「不是 X」会把 X 喂给模型）。
> 章鱼那组「触手打结／失重物理／漂浮碎片」是通用负词抓不到的 genre 专属翻车点，正是题材组必须独立存在的理由。

## 4. 体积感 / 重量感 技术清单（可直接抄）
- 尺寸锚 → 【资产锁】`+ 描述`：用已知物体对比，不写「巨大」。
- 运动信条 → 【动态锁】：只写正向「全程保持移动」，给触手／肢体分工（拖身 vs 破坏）；**不写「绝不…」，由题材组「静止摆姿／缓慢开场／中途减速」兜底**。
- 动量连续 → 【动态锁】＋逐镜 `画面：` 里各带一句：每镜用**正向**词重申「保持高速／冲势一贯到底／持续推进」（原稿的「不减速／不减冲势」按「正向板块禁否定句」改写，排除项由题材负词组兜底）。
- 解剖锁 → **只在【动态锁】写一次**：多肢体生物写死「完整连接、清晰分离、解剖正确、始终可见」。【资产锁】只写触手／肢体的**外观**，不重复解剖约束（用户原稿也是这么分的：「怪兽设计」写外观、「动态表现」才写解剖锁）。
- 重量动词 → 逐镜 `画面：`：碾碎 / 拽倒 / 撕裂 / 震裂 / 抛飞 / 极端应力解体 / 轰然坍塌。
- 光线特效 → 逐镜 `光线：`／`特效：` 两行，**每镜必写**；无新增就写「无明显新增特效，仅延续…」，不许留空。
- 题材负词 → 【负面提示词】：整组照抄 §3。

## 5. 与打斗手册 / 表情库 / 镜头库的分工
- **本模版管「巨物本身的体量、重量、解剖、连续运动」**——这是巨物场景独有的：打斗手册不管「巨型生物不减速」，表情库不管「怪兽无脸」。
- 若巨物同时与人／英雄对战 → 打斗手册的「打击感五件套、环境破坏四段式」照常加载，与本模版叠加，并额外追加「题材组·打斗动作」负词。
- 若巨物有可辨识面部表情 → 表情参考库照常查；多数巨物无脸，标 N/A。
- 镜头／机位参数仍查镜头参考库（灾难片常用低角度跟拍、屋顶横移、高空航拍、宽正面后退、超宽电影级缓拉）。**逐镜 `光线：`／`特效：` 已是主结构必写项，不再需要本模版额外开启。**
