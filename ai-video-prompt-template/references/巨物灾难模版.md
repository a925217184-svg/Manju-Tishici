# 巨物 / 怪兽 / 灾难场景模版（技能加成块）

> 本文件是 `ai-video-prompt-template` 六锁结构的**加成**，不是替代。脚本出现「巨物 / 怪兽 / 巨型生物 / 灾难 / 城市破坏 / 哥斯拉类 / 章鱼触手类」时加载它，把下面三件事补进六锁即可。
> 经验来源：用户实测一段「深海章鱼毁城」15s 提示词效果极好（巨物有体积感、动作有重量感、氛围对），其套路被提炼为本模版。

## 0. 触发词（命中即加载）
巨物、怪兽、巨型生物、怪物、灾难、城市破坏、毁城、哥斯拉、克苏鲁、章鱼、触手、海怪、地震、海啸、陨石、崩塌……（任一出现在脚本/需求里）。

## 1. 这段章鱼提示词为什么有效（套路拆解）
用户原话："巨物有体积感，动作有重量感，氛围也对"。拆出 5 条可复用的机制：

**(1) 体积感 = 尺寸对比锚，不写"巨大"**
- 原文：`身形高耸于周边摩天大楼之上` —— 用已知物体（摩天楼）当比例尺，AI 才会把生物画到楼顶高度。**只写"巨大""庞大"会被画成中等体型**。
- 备选锚：比 XX 建筑高 / 触手横跨整条街 / 阴影盖住半个广场 / 头部没入云层。

**(2) 重量感 = 运动信条 + 受力结果动词**
- 运动信条写死：`全程保持移动，绝不停滞或摆姿势` —— 巨物最忌"站着摆 pose"，一停就显假、显轻。
- 受力结果动词（**禁用"破坏"这种笼统词**）：`碾碎公交`、`撕裂楼体`、`震裂路面`、`将车辆抛向空中`、`极端应力下解体`、`轰然坍塌`。动词必须带"谁对谁施加了多大力量"才出重量。

**(3) 动量连续 = 每镜强调不减速**
- 原文：`毫不减速`、`始终不减冲势`、`仍继续着无情的推进`。多镜连续时，**每一镜都要重申运动不中断**，否则 AI 会在一镜里把巨物"定住"或"慢下来"。

**(4) 解剖锁 = 预防性写死（防 AI 翻车的精髓）**
- 原文：`八条触手始终保持完整连接、清晰分离、解剖结构正确，并在整个过程中始终清晰可见` —— 这是**主动**把 AI 最常翻车的点（多肢体、缠绕、断裂、错位、消失）用正描述钉死，**比事后在负词里禁更有效**。
- 同理适用于：多手多脚生物、成群敌人、机械多关节、分体式机甲。

**(5) 逐镜四字段 = 镜头 / 动作 / 光线 / 特效**
- 每个镜头拆成四行，其中**光线**和**特效**各自独立成行（六锁把光线并进了画面、特效并进了特效锁）。灾难片里光线是氛围主驱动（暴风雨白昼光、闪电、逆光火光、钢蓝暴雨光），单列更可控、不相互稀释。

## 2. 怎么接进六锁（加成，不是替换）
- **【资产锁】**：
  - 无现成怪兽/场景图（纯文生，如本次章鱼）→ 把"怪兽设计"整段作为**文字定金**写进【资产锁】，不写 `@`（没有图可锚）。
  - 有现成图 → 保留 `@怪兽名`、`@场景名` 引用，并把解剖约束挂在对应 `@` 行后。
- **【动态锁】（新增可选块，放在【资产锁】之后、【风格锁】之前）**：把 §1 的 (2)(3)(4) 整段写进来——运动信条 + 动量连续 + 解剖锁。这是六锁原本没有、巨物场景最需要的块。
- **【风格锁】**：质感明确写 `超写实灾难电影 / IMAX 级真实感 / 真实物理破坏`，**只选这一种**，不要混"电影感""Q版"两种。
- **【特效锁】**：只管"状态切换类"特效（如某器官/道具发光时机）。暴雨 / 粉尘 / 碎裂 / 玻璃幕墙这类**逐镜环境破坏**，移进【分镜】每镜的 `特效：` 行。
- **【分镜】**：每镜保留 `运镜：` + `画面：`，**光线是氛围主驱动时加一行 `光线：`**，环境破坏写进 `特效：`（或并进画面）。台词仍按时序内嵌画面。
- **【负面提示词】**：通用兜底之上，**追加 genre 专属负词**（见 §3）。


## 4. 体积感 / 重量感 技术清单（可直接抄进【动态锁】）
- 尺寸锚：用已知物体对比，不写"巨大"。
- 运动信条：全程移动、绝不停滞摆姿；给触手/肢体分工（拖身 vs 破坏）。
- 解剖锁：多肢体生物写死"完整连接、清晰分离、解剖正确、始终可见"。
- 重量动词：碾碎 / 撕裂 / 震裂 / 抛飞 / 极端应力解体 / 轰然坍塌。
- 动量连续：每镜重申"不减速 / 不减冲势 / 继续推进"。

## 5. 与打斗手册 / 表情库 / 镜头库的分工
- **本模版管「巨物本身的体量、重量、解剖、连续运动」**——这是巨物场景独有的，打斗手册不管"巨型生物不减速"，表情库不管"怪兽无脸"，镜头库不管"灾难片逐镜光线"。
- 若巨物同时与人/英雄对战 → 打斗手册的"打击感五件套、环境破坏四段式"照常加载，与本模版叠加。
- 若巨物有可辨识面部表情 → 表情参考库照常查；多数巨物无脸，标 N/A。
- 镜头/机位参数仍查镜头参考库（灾难片常用低角度跟拍、屋顶横移、高空航拍、宽正面后退、超宽电影级缓拉）。
