# 巨物 / 怪兽 / 灾难场景模版（原理与词库）

> **定位**：本文件的机制已**全部焊死**进 `ai-video-prompt-template` 的 v1.6 定稿主结构，不再是「命中才补的可选加成块」。它承担两件事：①解释这些机制**为什么有效**（原理）；②提供可直接抄的**词表**（尺寸锚、受力动词、genre 负词）。
> 经验来源：用户实测一段「深海章鱼毁城」15s 提示词效果极好（巨物有体积感、动作有重量感、氛围也对），随后拍板把套路焊死进结构，并给出资产锁的具体样式。

## 0. 触发词
巨物、怪兽、巨型生物、怪物、灾难、城市破坏、毁城、哥斯拉、克苏鲁、章鱼、触手、海怪、地震、海啸、陨石、崩塌……（任一出现在脚本／需求里）。

## 1. 这段章鱼提示词为什么有效（套路拆解）
用户原话：「巨物有体积感，动作有重量感，氛围也对」。拆出 5 条可复用机制：

**(1) 体积感 = 尺寸对比锚，不写「巨大」**
- 原文：`身形高耸于周边摩天大楼之上` —— 用已知物体（摩天楼）当比例尺，AI 才会把生物画到楼顶高度。**只写「巨大」「庞大」会被画成中等体型**。
- 备选锚：比 XX 建筑高 / 触手横跨整条街 / 阴影盖住半个广场 / 头部没入云层 / 成年人只到它脚踝。

**(2) 重量感 = 动态表现 + 受力结果动词**
- 运动信条写死：`这只生物全程保持移动，绝不停滞或摆姿势` —— 巨物最忌「站着摆 pose」，一停就显假、显轻。
- 受力结果动词（**禁用「破坏」这种笼统词**）：`碾碎公交`、`拽倒玻璃大楼`、`撕裂楼体`、`震裂路面`、`将车辆抛向空中`、`极端应力下解体`、`轰然坍塌`。动词必须带「谁对谁施加了多大力量」才出重量。

**(3) 动量连续 = 每镜强调不中断**
- 原文：`毫不减速`、`始终不减冲势`、`仍继续着无情的推进`。多镜连续时，**每一镜都要重申运动不中断**，否则 AI 会在一镜里把巨物「定住」或「慢下来」。

**(4) 解剖锁 = 预防性写死（防 AI 翻车的精髓）**
- 原文：`八条触手始终保持完整连接、清晰分离、解剖结构正确，并在整个过程中始终清晰可见` —— 这是**主动**把 AI 最常翻车的点（多肢体、缠绕、断裂、错位、消失）用正描述钉死，**比事后在负词里禁更有效**。
- 同理适用于：多手多脚生物、成群敌人、机械多关节、分体式机甲。

**(5) 逐镜 光线／特效／音效 独立成行**
- 灾难片里光线是氛围主驱动（暴风雨白昼光、闪电、逆光火光、钢蓝暴雨光），单列更可控、不相互稀释；音效也要跟着这一镜发生的事走（`混凝土坍塌声` 只在楼倒那一镜）。
- **v1.5 起（v1.6 定稿沿用）【分镜】每镜固定六行**：`镜头N（时码）／运镜：／画面：／光线：／特效：／音效：`。

## 2. v1.6 定稿里这些机制落在哪个板块（对照表）

> ⚠️ **复制区第一行必须是【风格锁】**（用户 2026-11-07 立）：先定全片基调再绑资产。下表按「原脚本字段」排列，不代表复制区板块顺序。

| 原脚本字段 | v1.6 定稿板块 | 状态 |
|---|---|---|
| 时长 15 秒 / 画幅比例 16:9 | **不进复制区** | 启动时问用户、AI 记住；时长用于核对区核算 |
| 风格 / 视觉风格 | 【风格锁】`风格：` **一行** | 默认（只选一种质感） |
| **怪兽设计** | **【资产锁】`一、"名称"角色设计：…`**（有图走 `@图名 作为…参考锚定图：`） | 默认，分隔符是 `：` 不是 `+` |
| **动态表现** | **【资产锁】角色条下另起一行 `动态表现：`** | 默认；运动信条／动量连续／解剖锁全在这里 |
| 场景设计 | 【资产锁】`二、"名称"场景设计：…` | 默认 |
| 0:00–0:02 镜头／动作／光线／特效 | 【分镜】每镜六行 | **光线／特效／音效焊死必写** |
| 音频设计 | 逐镜 `音效：` 行 | 环境底噪＋动作点音按镜分配 |
| 声线（如有台词角色） | 【音频锁】逐角色声线 | 无台词则整块省略 |
| 音频规格（无 BGM／无字幕） | 【负面提示词】通用组 | 写成 `BGM、配乐、人声台词、旁白、字幕…` |
| 反向提示词 | 【负面提示词】通用组 ＋ 题材组 | **题材组固定追加** |

**怪兽设计／动态表现为什么不另立板块**：用户 2026-11-07 给的样式里，它们本来就是资产锁里同一条角色设计下的两段。给了一张 `@刘备` 但要他是巨人，就写 `@刘备 作为刘备的角色参考锚定图：身形高耸于摩天楼之上…`，下面接一行 `动态表现：`；无图则写 `"刘备"角色设计：…`。**动笔前必须先问用户有没有角色图／场景图**，据此选 `@` 版或文字设计版。

**已删除的旧板块**：全局【特效锁】（v1.4 删）、【动态锁】（v1.5 删，内容并入资产锁）。【风格锁】里的 `时长：`／`画幅：`／`色调光位：`／`材质景深：`／`一致性：` 也一并删除——色调光位归逐镜 `光线：`、材质景深归 `画面：`／`特效：`、一致性由资产设计描述与逐镜画面继承承担。

**⚠️ 动态表现里的否定式要保留**：`绝不停滞或摆姿势`、`毫不减速` 这类是**运动信条**，按用户给定样式原样写；「画风排除句归负面词」那条规则只管 `不是 CG 宣传片／不是卡通` 这类**质感排除**，不适用于运动信条。运动类排除另由题材组 `静止摆姿／缓慢开场／中途减速／动作停顿／环境静止` 兜底。

## 3. genre 专属负词（题材组·巨物灾难，整组照抄）

```
多余肢体、触手缺失、触手缠绕打结、触手断裂脱离、解剖结构错误、
吸盘变形、漂浮的碎片、不真实的破坏、失重物理、缓慢开场、静止摆姿、
中途减速、动作停顿、环境静止、瞬移、低分辨率特效
```

> v1.6 定稿：这一组已焊死为【负面提示词】的「**题材组·巨物灾难**」，命中题材即整组追加，**不许只挑两三个词**。通用组（CG 宣传片质感／CG 过场动画／卡通外观／CGI 质感／塑料质感／BGM／配乐／人声台词／旁白／字幕／水印等）另行写一次，**两组不重复**。
> ⚠️ 画风排除句「不是 CG 宣传片、不是卡通」**只准写在负面区**，【风格锁】`风格：` 一个否定词都不留（正向写「不是 X」会把 X 喂给模型）。

## 4. 体积感 / 重量感 技术清单（可直接抄）
- 尺寸锚 → 【资产锁】角色设计：用已知物体对比，不写「巨大」。
- 运动信条 → 【资产锁】`动态表现：` 首句：全程保持移动、绝不停滞摆姿；给触手／肢体分工（拖身 vs 破坏）。
- 动量连续 → 【资产锁】`动态表现：` ＋ 逐镜 `画面：` 里各带一句「保持高速／冲势一贯到底／持续推进」。
- 解剖锁 → 【资产锁】`动态表现：` 末句：多肢体生物写死「完整连接、清晰分离、解剖正确、始终可见」。
- 重量动词 → 逐镜 `画面：`：碾碎 / 拽倒 / 撕裂 / 震裂 / 抛飞 / 极端应力解体 / 轰然坍塌。
- 光线／特效／音效 → 逐镜三行，**每镜必写**；无新增就写「无明显新增特效，仅延续…」，不许留空。
- 题材负词 → 【负面提示词】：整组照抄 §3。

## 5. 与打斗手册 / 表情库 / 镜头库的分工
- **本模版管「巨物本身的体量、重量、解剖、连续运动」**——这是巨物场景独有的：打斗手册不管「巨型生物不减速」，表情库不管「怪兽无脸」。
- 若巨物同时与人／英雄对战 → 打斗手册的「打击感五件套、环境破坏四段式」照常加载，与本模版叠加，并额外追加「题材组·打斗动作」负词。
- 若巨物有可辨识面部表情 → 表情参考库照常查；多数巨物无脸，标 N/A。
- 镜头／机位参数仍查镜头参考库（灾难片常用低角度跟拍、屋顶横移、高空航拍、宽正面后退、超宽电影级缓拉）。**逐镜 `光线：`／`特效：`／`音效：` 已是主结构必写项，不再需要本模版额外开启。**
