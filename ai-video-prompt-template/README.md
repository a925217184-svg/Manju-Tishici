# ai-video-prompt-template · 通用 AI 视频分镜提示词模板

> 一个**纯结构骨架**技能：不替你决定风格，只提供三层骨架（设定卡 → 统一 Style → 分镜 → 统一 NEG），把你填进去的内容锁住一致性。最大特色是**内置自动打斗检测 + 打斗参考手册**。

---

## 一、这个技能做什么

给任意题材产出专业 AI 视频提示词，适用于 即梦 / 可灵 / Runway / Sora / Veo 等。它不写死任何画风，风格与内容由每次的**设定卡**决定。

三层骨架：

- **第 0 层 · 设定卡**：8 项（主体角色 / 对手·障碍 / 场景 / 核心光效体系 / 风格基调只选一种 / 总时长镜头数 / 节奏基调 / 可选台词）。核心铁律：**核心资产（角色、武器、光效颜色）在设定卡写死后，全片每次出现用同一表述**。
- **第一层 · 统一 Style**：10 个槽位一整段（画质 → 渲染材质 → 光影 → 色调 → 动态元素 → 特效体系 → 构图 → 环境动态 → 一致性 → 节奏），槽位间不得风格矛盾。
- **第二层 · 分镜脚本**：每镜固定三件套 `镜头 N (起-止s) ＋ 运镜：＋ 画面：`。画面用「四段式口诀」——谁在动 → 怎么动 → 交互命中 → 反馈细节。
- **第三层 · 统一 NEG**：骨架为 画风排除 → 质感排除 → 结构崩坏 → 资产变坏形态 → 节奏 → 杂项。

## 二、什么时候用

- 撰写 / 生成 AI 视频提示词、分镜脚本、运镜提示词、负面提示词。
- 提到具体工具（即梦 / 可灵 / Vidu / Runway / Veo / Sora）的提示词需求。
- 用户提供视频脚本 / 小说片段，希望转成 AI 视频提示词。
- **含打斗 / 战斗 / 对决 / 交手 / 搏杀 / 追杀 / 混战 / 群战 / BOSS 战 / 妖兽战等动作场面**，或反馈「炫酷打斗 / 不够炸 / 打的不疼 / 没手感 / 动作不流畅 / 丰富特效 / 节奏拖沓 / 环境太干净」。

## 三、工作流（执行顺序）

1. **读取模板**：读 `references/template.md`，掌握三层层级、四段式画面口诀、运镜类型库与 checklist。涉及人物表情时同步查 `references/表情参考库.md`；定景别 / 机位 / 运镜时查 `references/镜头参考库.md`（含实测机位参数）。
2. **收集设定卡**：向用户确认或从其描述提取 8 项；缺失项做合理假设并标注（一次提问 ≤ 3 个）。
3. **填写统一 Style**：按 10 个槽位展开成一段。
4. **编写分镜**：套用节奏公式（动作战斗片 / 叙事氛围片 / 产品展示片），每镜三件套 + 四段式画面。
5. **打斗检测（命中即强制走手册）**：用场面词 / 需求词 / 画面判据扫剧本，命中任一 → 整篇读 `references/combat-handbook.md`，按七字段备料、打击感五件套、环境破坏四段式写；不命中就跳到第 6 步。
6. **交付单份 `.md`**（v1.3 起，v1.4 沿用）：`01_分镜提示词_<片名>.md`，上半「复制区」按固定板块写成可直接粘贴的纯 prompt，下半「核对区」写资产对照、时长核算、四库自检与待确认项。**不再另出 `.txt`、不再有「块 A / 块 B」**。资产图提示词同样并入一份 `03_生图提示词_<片名>.md`。

## 三点五、输出格式（v1.4 唯一标准）

文件固定两段，顺序不可颠倒：

1. **上半「复制区」**——纯 prompt，一个字都不许有说明 / 批注 / 修改痕迹 / 原脚本引用 / 待确认项。写成独立 fenced 代码块，预览面板可整块一键复制。
2. **下半「核对区」**——开头写死 `> 以下为核对内容，不复制到生成工具。`

复制区六个板块（顺序固定，无内容则整块省略）：

```text
【资产锁】   @图 ＋ 该资产的形象设计（尺寸锚 / 外观），一图一行
【风格锁】   时长 / 画幅比例 / 质感 / 视觉风格 / 色调光位 / 材质景深 / 一致性，全片只写一次
【动态锁】   运动信条 / 动量连续 / 解剖锁；巨物、追逃等持续运动题材必加，静态文戏可省
【音频锁】   声音边界：有无台词 / 有无 BGM / 环境底噪 / 动作点音 / 声线
【分镜】     每镜固定五行：镜头N（时码）→ 运镜：→ 画面：→ 光线：→ 特效：
【负面提示词】通用组 ＋ 题材组（固定追加），整段贴进负面词框
```

**v1.4 焊死的三件事**（整体骨架对齐用户实测极好的「巨物灾难片」提示词）：

- **全局【特效锁】已删除**——特效跟着每一镜发生，全部下沉到 `特效：` 行；`光线：`／`特效：` 两行**任何题材都不许省**，无新增就写「无明显新增特效，仅延续…」。
- **【负面提示词】留在复制区收尾**，且固定追加题材专属负词组（巨物灾难 / 打斗动作 / 实机录屏感 / 中文 UI / 对白文戏），整组照抄。
- **「怪兽设计」并入【资产锁】的 `+ 描述`**——给了 `@刘备` 但要他是巨人，就写 `@刘备 作为刘备角色的参考锚定图 + 身形高耸于摩天楼之上、…`；解剖锁归【动态锁】只写一次，不两边重复。

**【资产锁】固定句式**（照抄，不得改写）：

```text
@深海章鱼 作为巨兽角色的参考锚定图 + 身形高耸于周边摩天大楼之上、湿漉漉的深红紫色皮肤布满伤疤与纹理、八条粗壮有力的触手肆意挥舞
@刘备 作为刘备角色的参考锚定图 + 绿金甲、绿顶小冠、明黄披风、黑八字胡、右手持银色长剑
@近景古战场 近景 + @全景古战场 远景 = 古战场的场景参考锚定图
@站位单帧 作为角色在场景中的站位参考图，不直接作为帧使用，不得复刻使用
```

四条硬规矩：一个 `@` 只锁一件事；场景必须近景＋远景成对并写成 `= XX 的场景参考锚定图`（只有一张图时不写等式）；单帧图必须带「不直接作为帧使用，不得复刻使用」这句免责语，否则模型会把那张图的构图光位整块抄走；`@名` 与上传文件名严格一致且后面留一个空格。**无参考图时走「文字定金」**（不带 `@`，写 `深海章鱼 作为巨兽形象的文字定金 + 描述`）。

**画幅只写比例、绝不写像素分辨率**；每个新项目启动先问用户竖屏还是横屏，不预设默认值。

**单镜取用**：【资产锁】＋【风格锁】＋（【动态锁】）＋【音频锁】＋ 该镜五行 ＋【负面提示词】＝ 一条完整可粘贴 prompt。

## 五、最常用、最易踩的硬规矩（来自实战沉淀）

- **台词按时间序融入画面描述**，不单独成 `台词：` 行；多角色按发言先后依次嵌入。
- **人物一律 `@全名`**（如 `@关羽摊贩`），禁「关张 / 三兄弟」合并缩写；`@名` 后必须留一个空格，两个 `@` 之间用空格或顿号隔开。
- **运镜写死四要素**：景别（人物占画面比例）｜机位角度与高度｜运动方式＋距离／秒数｜落幅。但**以你当次偏好为准**——若你说「别写太复杂」，就只写景别＋运动。
- **动作细节锁惯用手**：关羽右手刀→左手捋髯；张飞右手单持丈八蛇矛→只许左手叉腰；骑马者右手持物、左手控缰。持械手不放开（被击飞时道具不消失）。
- **大型道具防玩具感四件套**：真实尺寸数字 ＋ 人形比例尺 ＋ 落地感（车辙 / 浮土 / 阴影 / 锈痕）＋ 贴近仰拍镜；NEG 加「玩具感 / 微缩模型感 / 比例失调」。
- **军阵四要素写死**：哪一方 ＋ 甲胄样式 ＋ 头盔盔缨 ＋ 手持兵器，整段保持一致。
- **旗帜纯色无文字**：所有旗帜 / 军旗 / 旌旗一律纯色布面，禁任何文字 / 徽记（AI 易在旗面生成乱码）。
- **发光道具平时不发光**，只在唤起全息 UI 那一瞬由顶端散射光柱凝出弹窗；角色眼睛不泛该光。
- **「画面太细碎」与「渲染 BUG 多」是两个相反信号**：收到 BUG 反馈先补物理细节（接触点 / 受力位移 / 形变 / 反馈），不要只加负面词。
- **NEG 按层分流**：整体设定层只放摄影机硬件参数＋风格速记；机位逻辑只在分镜层逐镜写死；NEG 层纯负面兜底。机位跑偏时单列「机位兜底（可选）」块，正常后摘掉。
- **正向板块零否定句**（2026-11-07 用户立）：【资产锁】【风格锁】【动态锁】【分镜】只写看得见的正向内容，禁「不是 CG 宣传片／不是卡通／绝不…／不…」；要排除的一律写进【负面提示词】通用组（`CG 宣传片质感、CG 过场动画、卡通外观、CGI 质感、塑料质感`）。正向写「不是 X」反而会把 X 喂给模型；【音频锁】的「无 BGM／无字幕」是既定规格写法，例外保留。
- **时长必须用台词字数反算**（字／秒：快/喊 6.0、普通 5.5、沉稳 4.5、卡顿/机械 3.5），向上取整到 0.5s；实测数据优先于估算。
- **分镜 ≠ 镜头**：一个说话人 = 一个独立镜头；一个分镜里塞 3–5 人发言必错。
- **改镜编号重映射**有 10 处同步清单（版本行 / 设定卡 / 标题时间码 / 语速表 / 生成单元表 / 对照表 / 审计表 / 声线锁 / 交叉引用…），漏一处就前后打架。

## 六、使用示例

输入：「把这段三国脚本转成分镜，主角关羽摊贩，对手张飞平民，含一场对砍」

→ 技能会：建设定卡（写死两人造型与武器）→ 填 Style → 写分镜（台词融入画面，每镜含 `光线：`／`特效：`）→ 检测到「对砍 / 斩击」自动加载 `combat-handbook.md` 强化打击感 → 交付一份 `01_…md`（上半复制区按 v1.4 固定板块＋逐镜，题材负词组固定追加；下半核对区；人物用 `@关羽摊贩` / `@张飞平民` 引用你上传的素材图）。
